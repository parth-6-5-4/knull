How the swarm stays bounded

Spawning is a validated proposal

Code checks parent authority, capabilities, depth, child count, dependency cycles and remaining allocation. Accepted tasks enter durable state before they can be assigned.

Waiting releases capacity

A coordinator with unfinished children enters waiting_children. It releases its lease and becomes eligible for aggregation only when the declared join conditions hold.

Recovery fences old workers

Leases expire under database time. A replacement attempt receives a new fence. A late old response cannot change authoritative results, even when its text looks correct.

Verification controls completion

Claims require evidence and independent assessment. Final report support still needs the HIVE-003 contract. Completed children, valid citation IDs and confident decisions do not alone prove success.
